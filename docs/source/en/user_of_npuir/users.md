# AscendNPU IR Users

This project has enabled multiple operator programming frameworks to connect to the Ascend backend and provides compilation optimization capabilities for Ascend. The following are examples of languages and frameworks that have been integrated with or use AscendNPU IR.

## Language Ecosystem

| DSL | Description |
| --- | --- |
| [Triton-Ascend](https://gitcode.com/Ascend/triton-ascend) | Provides Triton developers with rapid operator development and ecosystem migration capabilities for Ascend. |
| [TileLang-Ascend (branch npuir)](https://github.com/tile-ai/tilelang-ascend/tree/npuir) | A Tile-level programming framework that simplifies the high-performance operator development process, balancing development efficiency with low-level optimization capabilities. |
| [DLCompiler](https://github.com/DeepLink-org/DLCompiler) | A deep learning compiler that extends Triton, supporting cross-architecture DSL extension and intelligent automatic optimization. |
| [FlagTree](https://github.com/flagos-ai/flagtree) | An open-source AI compiler based on the Triton language, providing unified compilation capabilities across multiple backends. |
